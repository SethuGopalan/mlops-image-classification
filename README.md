

# MLOps Image Classification

This project is an image classification project being structured as an MLOps-style workflow.

## Project Goal
The goal of this project is to classify images using TensorFlow and gradually convert the work from a notebook-based machine learning experiment into a more organized MLOps project.

## Current Project Scope
At this stage, the project includes:
- data handling structure
- notebook-based model experimentation
- model storage structure
- reports structure
- configuration structure
- source code structure for future pipeline scripts

## Repository Structure
- `notebooks/` - Jupyter and Colab notebooks for experimentation
- `src/` - source code for data preparation, training, evaluation, and prediction
- `data/` - dataset placeholders and data organization
- `models/` - trained model files
- `reports/` - evaluation outputs and experiment results
- `configs/` - configuration files for training and experiments

## Current Notebook
The current notebook contains the initial TensorFlow image classification workflow.

## Planned MLOps Improvements
The next stages of the project will include:
- separating notebook code into Python scripts
- improving reproducibility
- saving model versions properly
- adding evaluation outputs
- building a prediction pipeline
- preparing the project for deployment

## Status
This repository is currently in the setup and structuring phase of the MLOps project.
